# MongoDB 数据库设计

数据库初始化脚本为 [`database/init-mongodb.js`](../database/init-mongodb.js)，运行方式见根目录 README。应用使用 Zod 校验输入，MongoDB 对四个集合另设置严格的 `$jsonSchema` 校验。跨题引用和跳转环由发布逻辑检查。

## 集合与关联

| 集合 | 关键字段 | 作用与关系 |
|---|---|---|
| `users` | `_id`、`username`、`passwordHash`、`createdAt`、`updatedAt` | 保存账号及注册时间；问卷的 `ownerId` 引用用户 `_id`。密码保存 bcrypt 哈希。 |
| `surveys` | `_id`、`ownerId`、`publicId`、`title`、`description`、`allowAnonymous`、`allowMultiple`、`status`、`deadline`、`draftQuestions`、`draftBaseVersionId`、`publishedVersionId`、时间字段 | 保存问卷元数据及可编辑题目数组；`publishedVersionId` 指向当前发布快照。状态为 `draft`、`published` 或 `closed`。 |
| `survey_versions` | `_id`、`surveyId`、`version`、`questions`、`publishedAt`、`publishedBy` | 保存每次发布的冻结题目与规则；`surveyId` 指向问卷。旧版本不覆盖。 |
| `responses` | `_id`、`surveyId`、`versionId`、`respondentId`、`respondentKey`、`dedupeKey`、`anonymous`、`clientSubmissionId`、`answers`、`path`、`submittedAt` | 一份提交对应一条文档；`versionId` 绑定作答版本，`path` 为服务端重放结果。 |

`draftQuestions` 和 `questions` 中的题目有 `qid`、`type`、`title`、`required`，并按题型使用 `options`、`validation`、`jumpRules`。选项是 `{id,text}`，答案是 `{qid,type,value}`。跳转规则是 `{id,when,targetQid}`；`when` 可以表示选项匹配、选项集合匹配或数值比较。评分题要求 `validation.min/max/integer`，取值为 1～10 内的整数刻度。

## 嵌套与引用的理由

题目顺序、选项和规则通常需要作为整份问卷读取和保存，因此题目嵌入问卷草稿，发布时复制进版本快照。答卷数量会持续增长，独立集合避免不断改写同一问卷文档，也方便按版本查询及设置提交唯一约束。旧答卷引用旧版本，题目修改后仍能按原题意统计。

MongoDB 文档模型适合不同题型使用不同 `validation` 字段、不同跳转条件的结构。它不意味着可任意写入：应用和数据库均做结构校验；新增题型仍需同步前端、校验、解释与统计代码。单份问卷和 `$facet` 结果仍受 MongoDB 文档大小限制。

## 索引

| 集合 | 索引 | 用途 |
|---|---|---|
| `users` | `username` 唯一 | 避免重名账号 |
| `surveys` | `publicId` 唯一；`ownerId, createdAt` | 公开链接查找；按时间列出自己的问卷 |
| `survey_versions` | `surveyId, version` 唯一 | 同一问卷版本号不重复 |
| `responses` | `surveyId, respondentKey, clientSubmissionId` 唯一 | 同一提交意图的幂等重试 |
| `responses` | `surveyId, versionId, submittedAt, _id` | 按问卷和版本筛选答卷 |
| `responses` | `dedupeKey` 唯一部分索引，仅约束字符串值 | `allowMultiple=false` 时阻止同一人再次提交 |

没有 `status + deadline` 复合索引。当前系统在服务启动、定期任务及相关请求中核对到期问卷，并将状态持久化为 `closed`。`respondentKey` 是服务端由用户和问卷计算的稳定 HMAC 标识；匿名答卷的 `respondentId` 为 `null`，但仍可进行幂等和防重复。创建者统计接口不会返回上述身份字段，当前也没有单份答卷详情读取接口。
